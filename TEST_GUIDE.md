## 🐛 Troubleshooting

### Issue: Phases not showing in left panel
**Solution:**
1. Check workflow actually executed (look for "COMPLETED" status)
2. Check database has phases data: Open DevTools → Network → Look for phases in response
3. Try hard refresh: Ctrl+Shift+R (or Cmd+Shift+R on Mac)

### Issue: Right panel shows "Select a phase to view details"
**Solution:**
1. Click a phase in the left panel to select it
2. Check console for errors: F12 → Console tab
3. Check phase data: F12 → Network → Check response JSON

### Issue: Phases not clickable
**Solution:**
1. Ensure phases list is not empty
2. Check browser console for JavaScript errors
3. Try a different workflow run

### Issue: Wrong data showing in right panel
**Solution:**
1. Clear browser cache: Ctrl+Shift+Del
2. Rebuild project: `npm run build`
3. Restart dev server: `npm run dev`

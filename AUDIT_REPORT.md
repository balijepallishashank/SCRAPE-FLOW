## 🔄 Data Flow Diagram

```
User Creates Workflow
        ↓
User Clicks Execute
        ↓
executeWorkflow() starts
        ↓
For each task:
  1. Create PhaseRecord
  2. Record inputs
  3. Execute task
  4. Record outputs
  5. Mark as completed/failed
        ↓
Store phases array in database
        ↓
User views Runs page
        ↓
User clicks "View Details"
        ↓
Load execution with phases
        ↓
User clicks phase → right panel updates
        ↓
Display inputs/outputs/errors
```

## ⚠️ Known Limitations & Future Improvements

### Current Limitations
1. **Phase numbering:** Auto-incremented, doesn't map to workflow nodes
2. **Output truncation:** Large files cut at 500 chars (may need adjustment)
3. **No retry on individual phases:** Only full workflow retry available
4. **No phase duration:** Only total execution time tracked

### Recommended Future Improvements
1. **Per-phase duration tracking:** Add `duration` field to PhaseRecord
2. **Phase comments/notes:** Allow users to annotate phases
3. **Download outputs:** Export phase outputs as files
4. **Phase grouping:** Collapse/expand task groups
5. **Execution replay:** Re-run from specific phase
6. **Comparison view:** Compare two execution runs side-by-side

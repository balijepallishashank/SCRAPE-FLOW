## Data Flow

### 1. Execution Phase
```
User clicks "Execute" in Workflow Editor
         ↓
executeWorkflow(workflowId) called
         ↓
Create WorkflowExecution record in DB
         ↓
For each connected task:
  ┌─────────────────────────────────────┐
  │ 1. Get task node data (inputs)      │
  │ 2. Create PhaseRecord               │
  │ 3. Execute browser automation task  │
  │ 4. Capture task outputs             │
  │ 5. Update phase.status = "completed"│
  │ 6. Store in phases array            │
  └─────────────────────────────────────┘
         ↓
Store phases array in WorkflowExecution.phases (JSON)
         ↓
Update execution status to "COMPLETED"
```

### 2. Display Phase (Your Page)
```
User navigates to /runs/[executionId]
         ↓
RunDetailPage loads execution from DB
         ↓
Parse phases JSON array
         ↓
Render left panel with phases
         ↓
User clicks phase
         ↓
selectedPhaseIndex state updated
         ↓
Right panel re-renders with phase details
         ↓
Display inputs/outputs/errors
```

### 3. Database Schema
```
WorkflowExecution {
  id: "abc123"
  workflowId: "xyz789"
  status: "COMPLETED"
  phases: "[
    {
      taskType: "LAUNCH_BROWSER",

      outputs: { "Web page": "Browser active" },

    },
    {

    }
  ]"
  logs: "Log line 1\nLog line 2\n..."

}
```

## Execution Example

### Workflow Definition
```json
{
  "nodes": [
    { "id": "node_1", "data": { "type": "LAUNCH_BROWSER", "inputs": { "Website Url": "https://example.com" } } },
    { "id": "node_2", "data": { "type": "PAGE_TO_HTML", "inputs": {} } }
  ],
  "edges": [
    { "id": "edge_1", "source": "node_1", "target": "node_2" }
  ]
}
```

### Execution Result (Phases Array)
```json
[
  {
    "taskType": "LAUNCH_BROWSER",
    "status": "completed",
    "inputs": {
      "Website Url": "https://example.com"
    },
    "outputs": {
      "Web page": "Browser instance active"
    },
    "creditsConsumed": 1,
    "error": null
  },
  {
    "taskType": "PAGE_TO_HTML",
    "status": "completed",
    "inputs": {},
    "outputs": {
      "HTML": "<!DOCTYPE html><html>...</html>"
    },
    "creditsConsumed": 1,
    "error": null
  }
]
```

### What User Sees
1. Left Panel: Two numbered phases with green checkmarks
2. Click "1. Launch browser" → Right panel shows Website Url input, Web page output
3. Click "2. Get html from page" → Right panel shows full HTML output (scrollable)

2. Response includes execution ID
3. Redirect to `/runs/[executionId]`

- Visible in JSON format

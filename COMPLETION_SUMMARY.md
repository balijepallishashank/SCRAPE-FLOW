## 💻 How It Works

### Data Flow
```
EXECUTION PHASE:
  User clicks Execute
  → executeWorkflow() runs
  → For each task: 
     • Record inputs
     • Run task
     • Record outputs
     • Add to phases array
  → Save phases[] to database

DISPLAY PHASE:
  User clicks "View Details"
  → Load execution + phases
  → Parse phases array
  → Show left panel with phase list
  → Wait for user click
  → Update right panel with selected phase
  → Display inputs/outputs
```

### Example Data Structure
```json
{
  "phases": [
    {
      "taskType": "LAUNCH_BROWSER",
      "status": "completed",
      "inputs": {
        "Website Url": "https://www.example.com"
      },
      "outputs": {
        "Web page": "Browser instance active"
      }
    },
    {
      "taskType": "PAGE_TO_HTML", 
      "status": "completed",
      "inputs": {},
      "outputs": {
        "HTML": "<!DOCTYPE html>..."
      }
    }
  ]
}
```
